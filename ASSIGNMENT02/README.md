# University Project Management System

## Overview

The University Project Management System is a web-based application designed to facilitate student administration services, access to university data, and effective communication among the university community. The system provides role-based access and functionalities for students, faculty, and administrators.

## Features

- **Role-Based Authentication:** Secure login for Students, Faculty, and Admins.
- **Student Dashboard:** Students can view their courses, projects, and submit assignments.
- **Faculty Dashboard:** Faculty members can manage student assignments, post grades, and manage projects.
- **Admin Dashboard:** Admins have complete control over the system, including CRUD operations for Students, Faculty, Courses, and Projects.

## Technologies Used

- **Backend:** Node.js, Express.js
- **Frontend:** Handlebars (HBS) for templating
- **Database:** MongoDB
- **Authentication:** Passport.js
- **Styling:** CSS

## Installation

### Prerequisites

- Node.js (v18.19.1 or later)
- MongoDB (local or cloud instance)
